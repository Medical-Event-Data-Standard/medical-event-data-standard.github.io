# MEDS Schema

This is the technical reference for the MEDS schema: the five schema components that make up a MEDS dataset,
how a dataset is organized on disk, how to validate data with the [`meds`](https://pypi.org/project/meds/)
Python package, and how to migrate between versions. For a conceptual introduction, start with
[What is MEDS?](/docs/intro_pages/what_is_MEDS).
