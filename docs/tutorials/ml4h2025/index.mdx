# MEDS ML4H 2025 Tutorial

_Building a model with MEDS: from the key design principles through data extraction, task definition, and model
building._

This page hosts the complete form of the notebooks explored interactively at the [MEDS ML4H 2025
Tutorial](https://github.com/Medical-Event-Data-Standard/MEDS_ML4H_2025_Tutorial), plus a pre-processing step
(step 4) added after the event.

## What you'll build

Over six notebooks, you'll take the openly available [MIMIC-IV demo](https://physionet.org/content/mimic-iv-demo/2.2/)
dataset from raw tables to trained, evaluated models for one running prediction task: **will a patient's ICU stay
last longer than 3 days?** Each step uses a tool from the MEDS ecosystem. A final step shows how to compare your
models with community baselines in MEDS-DEV.

| Step | Page                                                              | What you'll do                                                                   | Main tools                                                                      |
| ---- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 1    | [Getting Familiar with MEDS](./MEDS_intro.mdx)                    | Learn the MEDS data and metadata files on a small example dataset                | The MEDS schema                                                                 |
| 2    | [Converting to MEDS](./converting_to_MEDS.mdx)                    | Convert the raw MIMIC-IV demo tables into MEDS                                   | MEDS-Extract (built on MEDS-Transforms)                                         |
| 3    | [Extracting a Prediction Task](./extracting_prediction_tasks.mdx) | Turn the clinical question into a precise task definition and extract its labels | ACES                                                                            |
| 4    | [Pre-processing MEDS Data](./preprocessing_MEDS_data.mdx)         | Filter subjects and rare codes, remove outliers, and normalize the data          | MEDS-Transforms (with MEDS-Reader shown as an option)                           |
| 5    | [Build a Tabular Baseline](./build_a_model_tabular.mdx)           | Build features, train a logistic-regression baseline, and evaluate it            | scikit-learn, MEDS-Evaluation (with MEDS-Tab shown as the scalable alternative) |
| 6    | [Build a Neural Network](./build_a_model_NN.mdx)                  | Pre-process the data and train a neural network directly over MEDS data          | MEDS TorchData, Lightning                                                       |
| 7    | [Compare with MEDS-DEV](./compare_with_meds_dev.mdx)              | Relate your models to MEDS-DEV baselines, run them yourself, and contribute      | MEDS-DEV                                                                        |

## How to follow along

- **Just reading?** The pages for steps 1–6 render their full notebooks, outputs included, so you can follow
  the whole tutorial without running anything.
- **Want to run it?** Use the "Open in Colab" link at the top of each notebook page, or clone the [tutorial
  repository](https://github.com/Medical-Event-Data-Standard/MEDS_ML4H_2025_Tutorial) and run the notebooks
  locally. Step 4's notebook is in [this website's
  repository](https://github.com/Medical-Event-Data-Standard/medical-event-data-standard.github.io/tree/main/tutorial_notebooks/ML4H_tutorial)
  instead.
- **Start anywhere.** Steps 3–6 begin by downloading the MIMIC-IV demo in MEDS format, and steps 5 and 6 also
  download the task labels produced in step 3, so you can jump straight to the step you care about.
- **No credentialed data access needed.** Everything uses the open-access MIMIC-IV demo.
- **Want to look at the data first?** [Visualizing and Exploring MEDS Data](../visualizing_MEDS_data.mdx) runs
  the tools for exploring a MEDS dataset on the same MIMIC-IV demo.
