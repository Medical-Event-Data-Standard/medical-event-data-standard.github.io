# Build a (Neural Network) Model over MEDS data

:::info[First featured at ML4H 2025]

This tutorial was first featured in the [MEDS tutorial at ML4H 2025](./ml4h2025.mdx).

:::

In this tutorial, we'll use the dataset we extracted previously and build a _neural network_ model to predict
the task we extracted previously. See below for the jupyter notebook tutorial, rendered here, or check it out
online on [Google
Colab](<https://colab.research.google.com/github/Medical-Event-Data-Standard/MEDS_ML4H_2025_Tutorial/blob/main/jupyter_notebooks/Build_a_Model_(NN).ipynb>)
or on our [GitHub
Repository](<https://github.com/Medical-Event-Data-Standard/MEDS_ML4H_2025_Tutorial/blob/main/jupyter_notebooks/Build_a_Model_(NN).ipynb>)

:::tip

The notebook pre-processes the data with `MTD_preprocess`, a MEDS-Transforms pipeline that normalizes numeric
values, maps codes to integer indices, and tensorizes the result. It does not filter rare codes or remove
outlying values. [Pre-processing MEDS Data](./preprocessing_MEDS_data.mdx) walks through these stages, and
through cleaning stages you can run first, one at a time. You can then pass the cleaned dataset to
`MTD_preprocess` in place of the download.

:::
